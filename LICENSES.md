# Licenças de terceiros

O My Agent Studio não carrega nenhuma biblioteca em tempo de execução. O único
material de terceiros incorporado ao código é a geometria dos ícones.

## Lucide

`lucide-static` v1.31.0. Os dados foram convertidos de arquivos `.svg` para uma
estrutura de dados JavaScript, sem alteração das formas.

## Tipografia

Nenhuma fonte é distribuída ou baixada. A pilha declarada em `css/tokens.css`
usa Inter quando ela já estiver instalada no sistema e, caso contrário, recorre à
fonte de interface do sistema operacional.

## Marca

O nome, o símbolo (orb em gradiente), os avatares e todo o restante da identidade
visual do My Agent Studio são originais. Nenhum ativo, logotipo ou marca nominativa
de terceiros é utilizado.
